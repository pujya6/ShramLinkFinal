# ShramLink V2 — defensible presentation claims

The hackathon presentation itself is unchanged. These are candidate claims for
its later six-slide revision; preserve the original team's ShramLink identity.

| Suggested slide | Implemented claim | Evidence and qualification |
| --- | --- | --- |
| 1. Workers and factories | Hindi-first industrial recruitment for Delhi-NCR, with a simple worker/employer journey | Existing product scope and implemented flows; no user adoption or impact figures measured |
| 2. Speak to create a profile | A bounded Hindi conversation can ask, listen, interpret, clarify, correct and review after one Start | Complete flow demonstrated in automated Chromium with simulated speech; physical recognition/voice quality requires device preflight |
| 3. Hear and discover work | One-job cards, Hindi summaries, swipe/button/keyboard navigation, recoverable skips and a safe practice tutorial | Browser tests and screenshots; actual physical phone gestures are not verified |
| 4. Apply and track | Explicit application confirmation, duplicate prevention, employer review/selection and shared persistent status | Real Flask/SQLite integration and browser recruitment journeys |
| 5. Explainable and accessible | Skill/city/domain/experience ranking, exact-month eligibility, complete typed fallback, large controls and responsive layouts | Deterministic rules and automated tests; no advanced AI claim or formal accessibility certification |
| 6. Next steps | Test real Hindi voices/devices with workers, improve vocabulary from consented feedback, evaluate translation and deployment | Future validation and possible features, not shipped capability or promised outcomes |

## Safe concise feature inventory

- ShramLink brand and navy/turquoise industrial identity retained.
- Automatic conversational profile turns, spoken corrections/navigation and final
  confirmation; pause, stop, repeat, typing and service-error recovery.
- Hindi voice selection/preflight and a retroflex pronunciation sample.
- Exact mixed Hindi/Hinglish experience parsing with non-destructive migration.
- One-job discovery, spoken vacancy summaries, safe application confirmation,
  undo/restore and a skippable/repeatable tutorial.
- Persistent worker profiles, employer vacancies, applications and decisions.
- Existing session authentication, CSRF, role/ownership and capacity protections.

## Do not claim

- Universal browser/device speech support, a proven Mac pronunciation fix, or
  successful physical Hindi speech tests based on mocked APIs.
- “AI-powered matching,” a probabilistic suitability score or distance-based
  recommendations. Ranking is a transparent rule-based sort.
- Government/e-Shram/Aadhaar/GST verification, verified skills, background checks,
  guaranteed employment or confirmed employer legitimacy.
- Real OTP/SMS, automated payments, escrow, automatic payouts or payment gateways.
- Offline voice recognition, end-to-end browser-vendor audio privacy, live push
  notifications, cross-device skip synchronization or automatic Hindi translation.
- Production-scale reliability, field-tested low-literacy usability, accessibility
  certification, adoption/revenue, placement rates or social impact measurements.

Name data and credentials remain self-reported. An affirmative review confirms
what the worker submitted; it is not identity verification. Use exact final test
counts from `V2_TEST_RESULTS.md`, and describe automated and physical evidence
separately.
